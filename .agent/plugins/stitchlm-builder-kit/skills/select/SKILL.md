# Select the next tangible StitchLM outcome

Select exactly one authorized user-visible outcome from canonical tasking, not every dependency as a task. Use the three stages in plugin README. Small experiments or a build-ready specification are valid outcomes. Block ambiguous authority or concurrent ownership; never auto-create backlog or tracker records.

Read [protocol](../../references/protocol.md) and [engineering contract](../../references/engineering.md). Operate one bounded outcome at a time, preserve evidence, and report blockers without fabricating progress.

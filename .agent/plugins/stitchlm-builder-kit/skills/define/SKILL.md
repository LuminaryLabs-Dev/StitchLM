# Define a build-ready StitchLM experiment

Produce Stage1 plan preserving exact intent, acceptance, exclusions and authorized paths. Ground approach in source and current official backend documentation when applicable. State model/version/hardware prerequisites, numerical tolerances, dependency/typed tensor/KV/security contracts, commands, rollback and stopping conditions internally. Do not build until this bounded outcome is approved. Missing critical resources is BLOCKED, not an assumed pass.

Read [protocol](../../references/protocol.md) and [engineering contract](../../references/engineering.md). Operate one bounded outcome at a time, preserve evidence, and report blockers without fabricating progress.

# Prepare a bounded StitchLM delivery

Inspect complete artifacts/source integrity. Report exact outcome, candidate paths, pins, tests actually run and remaining gates. Source/software completion is not distributed runtime completion. No auto-publish, merge, deploy, release, tracker update or tag on pass. An explicit request-pinned integration contract permits the separate guarded integrate command into an authorized worktree, after evidence completion and native installation verification. Separate explicit authority and current-head/ownership checks are required for any repository delivery. Preserve memory honestly only within authorized scope.

Read [protocol](../../references/protocol.md) and [engineering contract](../../references/engineering.md). Operate one bounded outcome at a time, preserve evidence, and report blockers without fabricating progress.

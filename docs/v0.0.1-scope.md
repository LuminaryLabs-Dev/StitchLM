# v0.0.1 outcome and limits

Build a Rust native host, Rust native connector, Rust/WASM host console and
Rust/WASM connector. Connectors execute actual contiguous LFM decoder blocks;
the host owns embeddings, final normalization/head, sampling and the remaining
blocks. They cooperate on one model request, not independent complete-model
replicas. Shared crates own protocol, model, worker, host, platform, Nexus bridge
and UI. Product code is Rust; HTML and small worker/bootstrap JavaScript wrap WASM.

The pinned first model is LiquidAI/LFM2.5-350M. CPU F32 is the portable baseline.
Runtime context is 256 by default, at most 512; output isat most 128tokens. These are
initial safety bounds, not the model's advertised128kcontext. One request runs at
a time. The host currently retains the full model for reference/local coverage;
this milestone does not claim host-memory offload or distributed speedup.

Up to 20 connector registrations are bounded. Seven two-block ranges cover0..14;
host runs14..16. Additional devices are replicas, one healthy replica per range
selected for each request. Twenty connected devices do not mean twenty useful
parallel pieces of a16-layer model. Disconnect interrupts a stateful request;
restart from full prefill, never continue using a lost KV/convolution cache.

The current acceptance test uses at most four connectors, each with a 1 GBmemory
ceiling and a10% single-core CPU duty target. This supersedes the earlier20-device,
10MBstress request. OS virtual-address limits and measured RSS must be reported
separately; a duty target allows short compute bursts and is not a hard CPU quota.
The target Bonsai file is the user's exact27B Abliterated-LowDeg Q2_0 GGUF.
Its architecture/quantization must be proven before claiming end-to-end support.

Not claimed: production readiness, Mac/Windows/mobile hardware validation,
physical20-device Wi-Fi throughput, arbitrary-model support, automatic model
compression, browser background execution guarantees or faster token generation.

## Full pinned Bonsai text extension

The exact legacy 27B Abliterated artifact has a separate Rust 64-layer text backend.
Local weights stream from disk; distributed matrix commands use native/WASM
workers while the host owns all KV/recurrent state. The runtime is bounded to
512 tokens, greedy text decoding, and the pinned tokenizer. It does not inherit
the LFM contiguous-block assignment model. See [Bonsai runtime](bonsai-runtime.md)
and current full-model evidence for exact passed cases and performance limits.
